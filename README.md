# TasksFlow

**TasksFlow** is an Android application developed in Java as a practical project for learning Android application development.

The application focuses on task management, allowing users to organize their activities through a simple and intuitive interface.

## Features

- View tasks in a ListView.
- Add new tasks.
- Update existing tasks.
- Select and manage tasks.
- Organize task information.
- Display user account information.

## Android Concepts

The project covers several fundamental Android development concepts:

- **Activities** – creating and managing multiple application screens.
- **XML Layouts** – designing user interfaces.
- **findViewById()** – connecting Java code with XML interface components.
- **Intents** – navigating between activities and passing data.
- **Serializable** – transferring objects between activities.
- **ActivityResultLauncher** – handling results returned by other activities.
- **ListView and ArrayAdapter** – displaying collections of data.
- **Event Listeners** – handling user interactions and button clicks.
- **Toast** – displaying short notifications.
- **AlertDialog** – displaying confirmation and selection dialogs.
- **Options Menu** – implementing additional application actions.
- **ArrayList** – storing and managing collections of objects.
- **Java Streams and filter()** – filtering and processing collections.
- **Sorting** – organizing displayed data according to selected criteria.
- **Implicit Intents** – interacting with other Android applications.

## Technologies

- **Java** – application logic.
- **XML** – user interface layouts.
- **Android Studio** – development environment.
- **Android SDK** – Android application framework.
